🛡️ Women Safety Surveillance System
An AI-powered surveillance system that detects suspicious activity in real-time using CCTV footage. It uses YOLOv8 (Pose Detection) and XGBoost to analyze human behavior and sends alerts via a web interface.

🧠 Tech Stack: Python, YOLOv8, XGBoost, OpenCV, HTML/CSS/JS
⚡ Smart Bracelet: ₹150 IIT-developed device with 400KV shock, motion sensor & live GPS alert.

🚀 Features
Real-time suspicious activity detection
Frontend alert system (Red/Green light)
Emergency bracelet for women's safety
Scalable for urban CCTV integration
